# Русская локализация игры

## 📥 Установка

1. **Скачайте архив** с последней версией перевода.
2. **Распакуйте содержимое** архива в **корневую папку** игры, подтверждая замену файлов.
3. **Запустите игру** — русский язык будет установлен автоматически, независимо от выбранного в настройках языка.

## 📋 Описание

Переведены:
- ✅ **Весь текстовый контент** игры
- ✅ **Все изображения** и графические элементы интерфейса

При выборе **любого языка** в настройках игры будет отображаться русский.
